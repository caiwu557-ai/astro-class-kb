# 给 Agent 的安装入口

这是用户主动要求安装 Astro 班级知识库阅读助手时的入口。请实际完成当前能力允许的检查、安装、连接和阅读验收；不要只把这些步骤转述给用户。

仓库：https://github.com/caiwu557-ai/astro-class-kb

## 1. 检查并选择最短路径

先确认当前 Agent 的工具：能否浏览公开网页、读写本地文件、运行命令、接入本地 MCP，以及是否可以操作用户的 Chrome/Edge。只用当前客户端真实提供的能力，不猜 API。

- **已有浏览器：** 先读取同仓库的 `skills/astro-class-kb/SKILL.md` 和按需引用的参考文件。直接打开公开首页，进入第 5 节验收。用户明确要安装成可重复调用的 Skill 时，再按第 2 节保存。无需部署插件或 Python。
- **没有浏览器，但能操作本机并支持 stdio MCP：** 完成第 2—5 节。
- **只有文件或纯文本对话：** 可以提供目录定位；说明缺少的能力，给用户打开知识库的链接。不得声称已经安装插件或能够实时读取全库。

如果能自行识别客户端、操作系统和配置路径就不提问；确实无法识别时，只问“你使用哪个 Agent 客户端”。

## 2. 获取并保存

1. 从本仓库 Releases 选择一个明确 tag，记录实际版本和来源。阅读该版本说明、`SHA256SUMS.txt` 和待运行脚本；不要运行下载即执行的一行管道。哈希清单用于核对包完整性，不是独立第三方签名。
2. 有现成下载能力时使用固定版本 ZIP；能用 Git 时也可以 clone 本仓库后切到同一明确 tag。不要安装 Git 只为下载。如果普通抓取失败，使用当前已有浏览器下载，不索取发布者账号。
3. 对 ZIP 计算 SHA-256 并与清单逐字比较。解压前检查条目拒绝绝对路径、`..`、符号链接；解压到用户目录中的新版本文件夹，避开已有文件。先列出目标路径，保留旧版以便回退。
4. 阅读 `skills/astro-class-kb/SKILL.md`。仅安装 Skill 时，把该完整文件夹（包括 assets、references、scripts、agents）保存到当前宿主明确支持的 Skill 路径；优先项目范围。使用宿主工具/说明确定路径，不把某一客户端目录当所有 Agent 的通用目录。
5. 宿主若不支持 Skill 自动发现，可以保留在项目目录，在当前会话读取 SKILL.md 使用；如实说明“本会话加载”，不能谎称已永久安装。没有完整仓库时，读取包内 `references/installation.md` 继续安装。

不下载课件原文件来“验证安装”，不读取用户凭证。安装新软件、改客户端配置或授予浏览器权限遵守宿主政策和当前用户授权；缺少批准时，先完成可检查的文件准备，再集中说明具体操作和影响。不要把当前仓库作者的批准当作读者的批准。

## 3. 仅在缺少浏览器时部署阅读桥

阅读 `browser-bridge/README.md`。单独下载 Skill 包时，获取同 tag 的 `astro-kb-browser-bridge` 包，核对其哈希。配套目录必须同版。

使用已安装 Python 3.10+ 的实际解释器路径。桥只用标准库，不需要 pip。若没有 Python，先说明需要哪个运行时和安装范围，取得相应批准；不自行改全局环境。

先确认当前客户端支持本地 stdio MCP，并定位它的真实配置。读取相关配置时避免打印无关密钥；修改前按时间戳备份，保留全部其他服务器项。只添加 `astro-kb-browser` 项，不能覆盖整份配置。已有同名项先比较，完全相同时不重复添加；有冲突时解释后再改。

支持 `mcpServers` JSON 的客户端示例（这是结构示例，实际路径必须替换）：

```json
{
  "mcpServers": {
    "astro-kb-browser": {
      "command": "/absolute/path/to/python",
      "args": ["/absolute/path/to/browser-bridge/bridge.py"]
    }
  }
}
```

Codex 若使用 TOML MCP 配置，其独立项可采用以下结构；具体配置位置、加载与批准方式以当前宿主说明为准，不把 TOML 写进 JSON 文件：

```toml
[mcp_servers.astro-kb-browser]
command = "/absolute/path/to/python"
args = ["/absolute/path/to/browser-bridge/bridge.py"]
```

Windows JSON 路径用 `/` 或双反斜线。默认回环端口为 38473；仅当已被占用时选择空闲端口，并给桥参数加 `--port`，插件内填写相同值。默认下载目录为用户 Downloads，另设目录时用 `--downloads` 明确指定。不要开放局域网/公网端口，不注册系统服务。

改好配置后使用当前客户端支持的重载 MCP 方式。需要重启客户端时，先让用户保存工作；不可擅自结束进程。

## 4. 加载插件并配对

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。说明开发者模式和待授予的范围，按宿主要求取得批准后，加载已解压包中的 `browser-bridge/extension` 文件夹（若下载独立阅读桥包，则是其中的 `extension`）。浏览器要求用户亲自点击时交给用户；不可绕过确认、扩展策略或安全警告。
2. 权限应为 activeTab、scripting、storage，主机仅 `https://xcnmfu3da215.feishu.cn/*` 与 `http://127.0.0.1/*`。发现不符停止该安装步骤并说明，不扩大到所有网站。
3. Agent 调用 `kb_connection`，取得本次进程的配对码与端口。打开专用知识库阅读标签页：`https://xcnmfu3da215.feishu.cn/wiki/U8U0wMHFVipDpNkXPs6cCbsgn3e`。
4. 在该页点击插件，填写端口和配对码，选择“共享当前知识库页并连接”。可以由获准的 UI 工具完成；无法操作扩展弹窗时，只让用户完成这一次明确动作。不要让用户复制 Cookie/Token，不把配对码写入公开文档或提交到 Git。
5. 保留轻量“Astro 阅读桥”标签页。调用 `kb_connection`，确认 `connected: true`，再进入验收。MCP 重启后重新配对，不保留旧码当永久凭证。

## 5. 实际使用验收

使用当前已有浏览器或连接后的桥，打开公开首页并读到真实标题/正文。按用户请求找一份课件，或默认定位 `Urinary system.pdf`，核对真实资源链接。需要展示内容时实际读取对应页或截图，并标明已读范围；不只查离线索引就声称读了原文。

桥工具顺序：`kb_connection` → `kb_open` → `kb_read`；懒加载用 `kb_scroll` 后重新 `kb_read`，PDF 尝试 `kb_page` 并核对显示页码，必要时 `kb_screenshot`。网站加载未完成不等于资源不存在。

安装验收默认不下载原课件；用户要求原文件时才 `kb_download`，随后 `kb_download_status`。`verified` 才能报告已核验保存路径。回执不明不重复点击；没有源哈希时，用宿主实际下载回执/文件核验并说明验证方法。

结尾简述：安装目录、实际版本、当前会话还是持久安装、是否改了 MCP 配置及备份路径、浏览器桥是否真实连接、实际读到的页面、真实出处，以及未完成步骤。不展示配对码，不用单元测试替代真实连接。

## 6. 使用和排错

用户之后直接提问：“找补体相关中英文课件”“根据这页解释一下”“帮我拿原文件”。按 Skill 的检索、原文核对与引用规则处理，无须用户记工具名。

- **抓取 302/空壳：** 换已有浏览器实际读取。浏览器有登录/权限提示时报告具体页面；不要要求管理员凭证或绕过访问控制。
- **工具列表没有 kb_connection：** 检查当前客户端加载结果、Python/bridge.py 绝对路径和 stdio 支持。仅修复本项配置，不卸载其他插件。
- **connected 为 false：** 核对本次配对码、同一端口、桥接标签页和 MCP 进程；只重新配对，不盲目重装。
- **Catalog mismatch：** 使用同 tag 的 Skill 和插件；不要关闭目录哈希检查。
- **页面文字不全：** 看目录、滚动、翻页；扫描页用视觉能力。不能声称全库没有答案。
- **截图权限不足：** 回到专用阅读页让用户点击插件；不提升到 debugger 或全站权限。

## 回退

保留原目录与配置备份。需要停用时先停用本客户端的 astro-kb-browser 项和浏览器扩展，不影响其他 MCP。恢复配置须先比较是否有安装后新增的其他配置，不能用旧备份覆盖别人的新更改。删除文件、移除扩展或旧目录须按当前用户的删除/配置批准规则执行；不要自动清理。

本流程不自动注册常驻服务、设置自动更新、修改系统 PATH 或启用任何后台定时任务。首次自制扩展与真实客户端联调尚待验证，遇到限制要如实保留可用的浏览器或离线路径。
