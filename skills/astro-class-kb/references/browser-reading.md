# 公开浏览器工作流

## 已验证事实（2026-10-25）

未执行登录操作，内置浏览器直接读取了公开首页，以及 `Urinary system.pdf` 的 26 页预览。页面显示“互联网公开”。
点击真正的“下载”按钮后，浏览器下载事件返回了本地 PDF；下载文件的 SHA-256 与用户提供的原文件一致。
同一公开 URL 的普通 HTTP 请求出现 302 循环；这仅说明 HTTP 路径在当时的环境失败。
没有读取浏览器 Cookie、账户缓存、网页私有运行状态或复制管理员凭证。
PMed 的底层共享字段曾显示 tenant_readable，但 Wiki 链接在浏览器中仍可读取。不能把底层文档字段单独当作 Wiki 实际访问结果，也不能据此声称课程没有资料。
离线发布对这类差异从严：只保留公开首页已列出的导航，不从管理员接口导出权限不明确的正文。读者用自己的浏览器访问，受网站实际权限约束。

## 通用步骤

使用宿主实际提供的浏览器 API，不假设其他 Agent 支持 Codex 的函数名。
先打开目录命中的直接链接，读取页面状态。尚在加载时重新获取状态，不把空外壳当成无资料。
正文链接可能比左侧目录更容易定位；目录本身也有虚拟化，首屏不能代表全部子页。
优先使用页面可见的章节目录锚点跳到目标段落，再读取加载后的正文。标题可能包含飞书生成的不可见格式字符，可清理标题显示，不改写正文含义。
读取开发者的话或长问答时，滚动正文容器到所需段落，再重新取 DOM/可访问性快照。记录实际读到的章节。

## Codex 内置浏览器示例

遵守当前宿主的浏览器工具文档，使用 `cua_repl` 创建或绑定内置浏览器页。已绑定的页复用，不必反复打开标签页。
当前工具若提供 Playwright，可用页面真实语义定位：`getByRole('button', {name:'下载', exact:true})`。
应先监听 `waitForEvent('download')`，再点击下载，最后读取下载对象的 `path()`。API 是否存在，以当前工具文档为准。
如果事件未返回文件，不能报告成功；说明“下载未验证”，保留原入口。

## PDF / PPT 与图片

原文件名、页数与版本先确认。浏览器可访问性树可能把 PDF 文本拆成逐字节点；不要按节点间换行猜段落。
优先下载并按相关页读取；无下载能力时用截图和视觉工具核对，保留页码。
若有页码输入框，使用工具支持的原生填值/按键方式跳页，并核对显示页码后再引用。
图表、切片和扫描页需要视觉读取；关键词索引为空不代表该页空白。

## 不能做的推断

公开页面可读不代表其他私有系统可读；资料下载权限与网页阅读能力分别判断。
没有浏览器工具、插件未连接、当前页未加载、文件不可读时，明确具体限制；不要要求所有读者接入管理员 CLI。
